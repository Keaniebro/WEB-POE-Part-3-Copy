# Harmony Hub - Web Development PEO Part 1 overview:
Welcome to the project repository for "Harmony Hub", an online-exclusive musical instrument store deserve store designed and built from scratch as part of my web development portfolio coursework. 

## Project Overview
Harmony Hub is tailored for professional musicians, studio producers, and passionate learners across South Africa. The platform features an online catalog of high-end instruments—including grand pianos, digital keyboards, guitars, violins, and drum kits—priced in South African Rands (ZAR).

* **Live Regional Hubs:** Cape Town & Johannesburg
* **Currency:** ZAR (R)

## Design & Aesthetic
* **Theme:** Sleek, modern dark theme (`#121212`, `#1a1a1a`) paired with luxury gold accents (`#d4af37`) for an upscale musical feel.
* **Layouts:** Fully responsive grid and flexbox layouts designed to adapt cleanly across different desktop and mobile screen sizes.

# Harmony Hub - Project Documentation & Redesign

## 1. Project Planning & Proposal

### Goals & Objectives
- Modernize the visual layout of Harmony Hub to provide an intuitive user experience.
- Implement responsive design principles ensuring compatibility across desktop, tablet, and mobile screens.
- Provide clear navigation across all five pages: Home, About Us, Products, Enquiry, and Contact Us.

### Current Website Analysis
- **Strengths:** Clear multi-page structure and functional navigation menus.
- **Weaknesses:** Outdated styling, lack of modern CSS grid/flexbox layouts, and poor mobile scaling.
- **Redesign Solution:** A complete CSS overhaul utilizing a professional color palette, card-based layouts, and responsive media queries.

### Features & Functionality
- Consistent header, footer, and navigation bar across all pages.
- Interactive form elements and buttons with hover states.
- Responsive design adapting dynamically to various screen resolutions.

*(Placeholder note: Low-fidelity wireframes mapped out layout structures for desktop and mobile viewports prior to coding.)*

### Technical Requirements
- HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- External CSS stylesheet (`style.css`) utilizing Flexbox and Grid.
- Responsive breakpoints via CSS Media Queries.

### Timeline
- **Phase 1 (Planning & Research):** Scope definition, current site analysis, and sitemap design.
- **Phase 2 (HTML Structure):** Building out the five core pages with semantic tags.
- **Phase 3 (CSS Styling & Responsiveness):** Applying visual styles and media queries for multi-device support.
- **Phase 4 (Testing & Documentation):** Cross-browser testing, code cleanup, and final GitHub submission.

### Budget & Resource Estimation
- **Development Time:** Estimated 15 hours of design and implementation.
- **Software Tools:** Visual Studio Code, Git/GitHub, browser developer tools (cost: R0 / Open-Source).
- **Hosting / Assets:** Free local development environment and open web fonts/icons.

### Two Design Proposals
1. **Proposal A (Minimalist Corporate):** Focuses on stark white spaces, sharp borders, and a corporate blue color theme.
2. **Proposal B (Modern Interactive Card-Based - Chosen):** Utilizes soft shadows, rounded card containers, a vibrant navy and light-blue palette, and high user engagement focus.
